### 🚀 Featured projects

**🎫 [AI-Assisted IT Service Desk](https://github.com/maisha272/AI-assisted-IT-service-desk)**
A service desk for a managed service provider. An AI triage agent uses RAG over past fixes to suggest a category, priority and solution steps for each new ticket, and a support agent approves or edits every suggestion before anything changes. It also has role-based access, SLA tracking with live countdowns, Microsoft Teams alerts, email-to-ticket, and reporting. It's backed by 130+ tests and a CI/CD pipeline to Azure.
`C#` `ASP.NET Core` `EF Core` `React` `TypeScript` `OpenAI` `Azure` `GitHub Actions`

**🔭 Great Melbourne Telescope Restoration** · *Museums Victoria internship*
Full-stack software for the restored telescope, running on a Raspberry Pi 5 and communicating with BiSS-C encoders.
`Flask` `Vue.js` `Raspberry Pi 5` `Serial comms`

**🛒 [TechStore](https://github.com/james-luong/COS30043-Interface-Design-Final-Project-2026)** · *group project*
A full-stack e-commerce web app with user and admin accounts, built as a Vue 3 + TypeScript single-page app on top of a PHP REST API (documented with OpenAPI/Swagger) and a MySQL database. It includes OTP two-factor login and an AI chatbot powered by the Claude API, and it's deployed to Swinburne's Mercury server. I owned authentication and login (including OTP two-factor verification), the email integration with EmailJS, and the Claude-powered AI chatbot.
`Vue 3` `TypeScript` `Vite` `Pinia` `PHP` `MySQL` `OpenAPI` `Claude API`

**🌦️ [Weather Dashboard](https://github.com/Katsudon27/SWE40006_GroupProject_SourceCode)** · *group project*
A Flask web app that shows real-time weather and a 5-day forecast for any city using the OpenWeather API, with friendly error handling, a responsive Bootstrap UI and a health-check endpoint. It's containerised with Docker and has a GitHub Actions CI/CD pipeline covering linting (flake8), automated tests (pytest with coverage) and deployment.
`Python` `Flask` `REST APIs` `Bootstrap` `Docker` `pytest` `GitHub Actions`

**🩺 [Multi-Agent Medical Decision Support System](https://github.com/maisha272/Multi-Agent-Medical-Decision-Support-System_SourceCode)** · *group project*
An LLM-based system with four agents. An Intake agent extracts symptoms, a Medical agent suggests diagnosis and treatment, a Validation agent checks against historical cases (RAG via Pinecone) and drug interactions (RxNav API), and an Orchestrator routes and retries. I built and evaluated the Medical agent. Designed the main architecture.
`Python` `smolagents` `MCP` `Pinecone` `Gemini` `Ollama`

**🌧️ Agent-Based Stormwater Planning (WSUD) Decision Support** · *capstone, client: Frankston City Council*
A multi-agent pipeline that recommends rain gardens, wetlands or rainwater harvesting for different urban conditions. 
`Python` `PySWMM` `LLM agents`

**🔐 Secure IoT Monitoring Platform**
A three-level PKI chain with mutual TLS across four IoT client devices, a live Flask + Socket.IO dashboard, rolling-window anomaly detection, and a real-time intrusion detection system on MQTT logs.
`Python` `Flask` `Socket.IO` `OpenSSL` `MQTT` `Apache`

**💊 [MediTrack](https://github.com/maisha272/MediTrack)**
An Android app for tracking medications. *(It helps tracking medications and gives reminder to take medication)*
`Kotlin` `Android`

**🧠 NeuroSense: EEG Pain Detection for Non-Verbal Patients** · *engineering innovation project*
Detects pain in patients who can't communicate it, such as people with dementia or patients in ICU, from EEG band-power features. I built the Random Forest + MLP ensemble model, which reached **90.8% accuracy** and **0.974 AUROC**.
`Python` `Machine Learning` `EEG signal processing`
